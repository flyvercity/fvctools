# Flyvercity Data Format Schema

This directory contains autogenerated documentation for the `.fvc` data format schema, derived from [`src/fvc/tools/df/schema.yaml`](../../src/fvc/tools/df/schema.yaml).

## File Structure

Every `.fvc` file is a [JSON-Lines](https://jsonlines.org/) file where:

1. The **first line** is always a [METADATA](METADATA.md) record describing the file content and origin.
2. Subsequent lines are data records of the type specified in the metadata.

## Record Types

| Record                                 | Description                                                              |
| -------------------------------------- | ------------------------------------------------------------------------ |
| [METADATA](METADATA.md)                | File metadata — content type, source format, and origin                  |
| [FLIGHTLOG](FLIGHTLOG.md)              | Flight log entry with position, attitude, cellular signal, and GNSS data |
| [RADARLOG](RADARLOG.md)                | Radar log entry with polar or geographic position                        |
| [FUSION\_REPLAY](FUSION_REPLAY.md)     | Fusion engine replay event                                               |
| [CAPTURE\_MESSAGE](CAPTURE_MESSAGE.md) | Captured MQTT message                                                    |
